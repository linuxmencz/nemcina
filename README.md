# Němčina pro Čechy (beta)

Webová aplikace na učení němčiny pro Čechy, úrovně A1–B2, s namluvenými slovíčky, dialogy, výslovností a gramatickými cvičeními.

**Web:** https://linuxmencz.github.io/nemcina/

> ⚠️ **BETA verze.** Osobní nekomerční projekt, který se teprve zkouší. Obsah (překlady, rody, plurály, přepis výslovnosti, gramatika, dialogy) napsala umělá inteligence a nebyl odborně zkontrolován, může obsahovat chyby.

Postup se ukládá jen v prohlížeči zařízení; aplikace nesbírá žádná data a nevolá žádné cizí servery.
